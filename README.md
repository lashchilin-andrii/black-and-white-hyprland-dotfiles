# 🖤 B&W Hyprland Dotfiles

A minimalist, clean, black-and-white Hyprland environment setup for Arch Linux (or any Wayland-based distribution).

---

## 📦 Components

This repository includes configuration files for:

    🎮 Hyprland — Dynamic tiling Wayland compositor

    📊 Waybar — Highly customizable Wayland status bar

    🚀 Rofi — Application launcher and window switcher

    💅 Kitty — GPU-accelerated terminal emulator

    🔔 Dunst — Lightweight notification daemon

    💻 Fastfetch — Minimalist system information tool

    🔐 SDDM — Display/login manager

    🎨 GTK 3/4 & Qt5/6 — Unified GTK and Qt application theming

    📸 Swappy — Wayland screenshot annotation tool

    📁 XDG User Dirs — Standard user directory structure
